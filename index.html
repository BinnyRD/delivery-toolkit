Delivery tools that explain themselves

Three lightweight tools for project and business analysis work. Each one works out status from the data and tells you why, so a Red or Amber comes with a reason you can act on.

DD

Delivery Desk

A portfolio view of projects and day-to-day operations.

  • Red/Amber/Green with the reason
  • RAID log for every project
  • Intake scoring for new requests
  • One-click weekly status report
Open Delivery Desk → PD

Project Desk

One project, run properly from plan to close.

  • Plan and timeline with dependencies
  • Budget, change requests, stakeholders
  • Benefits, lessons and improvement
  • Rules that suggest the admin work
Open Project Desk → BA

BA Desk

Requirements to sign-off, with fewer surprises in UAT.

  • Flags vague and untestable requirements
  • Stories checked for sprint readiness
  • Gap → requirement → story → test trace
  • Exports a requirements specification
Open BA Desk →

Each tool opens with fictional sample data. Anything you change is saved in your own browser only; nothing is sent anywhere. Use Back up in each tool to keep a copy.
